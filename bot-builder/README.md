# Hermes bot builder

Hermes bot builder

`bot-builder` · v1.0.0 · Ilyass · MIT

## Install

```bash
hermes template install https://raw.githubusercontent.com/Ilyassbm/agent-templates/main/bot-builder/bot-builder.htemplate
```

Or Hermes Desktop ▸ Templates ▸ Install, paste the link, review the preview.
Needs the Agent Templates plugin: `hermes://plugin/install?repo=Ilyassbm/hermes-templates&enable=1`
